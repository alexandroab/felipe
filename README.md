# 🏫 Sistema de Gestión – Politécnico Felipe Soriano Bello

**Constanza, R.D.**

Aplicación web completa de gestión tecnológica para uso del dinamizador TIC del centro. Funciona 100% en el navegador, sin servidor ni base de datos externa.

## 📋 Módulos

| Módulo | Descripción |
|--------|-------------|
| 📋 **Agenda** | Directorio de contactos (docentes, estudiantes, admin, apoyo, externos) con búsqueda y filtros |
| 💻 **Inventario** | Control de equipos tecnológicos, registro de mantenimientos y reparaciones |
| 🎓 **Asistencia** | Registro de asistencia técnica prestada a estudiantes, docentes y personal |
| 🏫 **Visitas** | Registro de visitas de acompañamiento a docentes y visitas de superiores |

## 🚀 Uso en GitHub Pages

1. Sube este repositorio a GitHub
2. Ve a **Settings → Pages**
3. En "Source" selecciona `main` branch y carpeta `/root`
4. Guarda — tu URL será: `https://tuusuario.github.io/tu-repo/`

## 💾 Almacenamiento

Todos los datos se guardan en el **localStorage** del navegador. Cada módulo permite exportar a CSV para respaldo.

## 📥 Exportación

- Agenda → exporta CSV con todos los contactos
- Asistencia → exporta CSV con historial de asistencias
- Visitas → exporta CSV con todas las visitas
